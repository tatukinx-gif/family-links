# Family Links

Googleスプレッドシートで管理する、シンプルな個人・家族向けお気に入りサイトリンク集です。

## 主な機能

- アイコン型のお気に入りサイト一覧
- ファビコン自動取得
- カテゴリ別の絞り込み
- 利用者別表示（共通・自分・家族）
- サイト名検索
- 表示順の切り替え
- ライト・ダークモード
- PC・スマートフォン・タブレット対応

## 使用技術

- HTML5
- CSS3
- JavaScript（ES Modules）
- Google Sheets（CSVデータ管理）
- GitHub Pages（無料ホスティング）

## データ管理

リンク情報はGoogleスプレッドシートの `Links` シートで管理します。

| 列名 | 内容 |
| --- | --- |
| name | サイト名 |
| url | リンク先URL |
| category | カテゴリ |
| audience | 利用者区分 |
| order | 表示順 |
| icon_url | 任意のアイコンURL |
| description | 説明 |

スプレッドシートの変更内容は、公開CSVを通じてWebページに反映されます。キャッシュなどにより、反映まで時間がかかる場合があります。

## サイト公開

GitHub Pagesを利用して公開します。

## セキュリティ

公開CSVおよびGitHubリポジトリには、パスワード、APIキー、個人情報などの秘密情報を保存しないでください。

利用者別表示は表示上の分類であり、アクセス制限機能ではありません。
